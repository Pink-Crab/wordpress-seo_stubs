# Yoast SEO Stubs

Yoast SEO stubs for static analysis (PHPStan, Psalm, IDEs), generated by
[stub-forge](https://github.com/Pink-Crab/stub-forge) with
[php-stubs/generator](https://github.com/php-stubs/generator).
Includes private and protected members. Each git tag matches the plugin
version the stubs were generated from.

## Source

- Original plugin: <https://wordpress.org/plugins/wordpress-seo/>
- Plugin homepage: <https://yoa.st/1uj>

## Installation

```
composer require --dev pinkcrab/wordpress-seo_stubs:27.4
```
